# VOID — Streetwear Store

A dark, modern streetwear e-commerce concept built with HTML, CSS, and vanilla JavaScript.

**Live Demo:** https://nikolasmarantas9.github.io/void-streetwear-store/

## Overview

VOID is a front-end e-commerce portfolio project inspired by contemporary streetwear brands. It combines a minimalist dark aesthetic with interactive product browsing and shopping features.

The project was built to practise front-end development, responsive web design, DOM manipulation, and browser-based data persistence.

## Features

- **Product collections:** Browse clothing and sneakers.
- **Product details:** View product information and select available sizes.
- **Shopping bag:** Add products, adjust quantities, remove items, and view the subtotal.
- **Persistent cart:** Cart contents are saved in the browser using `localStorage`.
- **Saved favourites:** Save products and revisit them later.
- **Product filtering:** Explore the available collections and saved items.
- **Customer reviews demo:** Review entries are stored locally in the current browser.
- **Responsive design:** Layout adapts to desktop and mobile screens.
- **Interactive UI:** Animations, product cards, and modal interactions.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Browser `localStorage`
- GitHub Pages

## Getting Started

### Run locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Browse the products and test the interactive features.

No build tools or package installation are required for the current static version.

## Important Notes

This is a **front-end portfolio/demo project**, not a production-ready online store.

- Checkout does not process real payments.
- There is no backend, server-side inventory, or customer account system.
- Cart contents, favourites, and demo reviews are stored in the current browser and do not synchronise between devices.
- Do not enter real payment details or sensitive personal information.
